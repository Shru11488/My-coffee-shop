# ☕ Coffee Shop Web Application

## 📌 Description
A modern and responsive coffee shop web application built using Next.js and React. The application allows users to browse products, add items to cart, and experience a smooth and interactive UI.

---

## 🚀 Features
- Dynamic product/menu browsing  
- Add to cart functionality  
- Responsive design for mobile and desktop  
- Interactive UI components  
- Smooth navigation using Next.js routing  

---

## 🛠 Tech Stack
- Next.js  
- React.js  
- Tailwind CSS  
- Redux (State Management)
